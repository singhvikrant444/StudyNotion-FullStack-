# StudyNotion

StudyNotion is a full-stack EdTech platform built using the MERN stack.

## Tech Stack

Frontend:
- React.js
- Redux Toolkit
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

Other:
- Cloudinary
- Razorpay

## Features

- User authentication
- Student dashboard
- Instructor dashboard
- Course creation
- Course enrollment
- Course management
- Payment integration
- Profile management
- Media upload
